# Лаба 3 - «Артдуэль» (свой вариант)

Игра на Python + tkinter: поединок двух танков. Вводишь угол и силу -
стреляешь по танку компьютера, он отвечает. После каждого выстрела оба танка
случайно меняют позиции, а ветер (тоже меняется каждый ход) сносит снаряд в
сторону - так что фигачить одним и тем же углом не выйдет. У кого первым
кончится HP - тот проиграл.

Запуск: `python main.py`

- `main.py` - вся игра (окно, меню, холст, анимация снаряда)
- `bgm.wav` - фоновая музыка (8-битное арпеджио, зациклено)
- `docs/` - прототипы интерфейса и скриншоты для отчета
