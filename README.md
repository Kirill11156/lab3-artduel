# Лаба 3 - «Артдуэль» (свой вариант)

Игра на Python + tkinter: поединок двух танков. Вводишь угол и силу -
стреляешь по танку компьютера, он отвечает. У кого первым кончится HP - тот
проиграл.

Запуск: `python main.py`

- `main.py` - вся игра (окно, меню, холст, анимация снаряда)
- `docs/` - прототипы интерфейса и скриншоты для отчета
